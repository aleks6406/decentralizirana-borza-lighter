# Decentralizirana borza Lighter

## Opis projekta

Projekt je namenjen spremljanju in analizi podatkov iz order booka decentralizirane borze Lighter.

## Funkcionalnosti

- Testiranje povezave z API-jem Lighter
- Pridobivanje trgovalnih parov
- Pridobivanje podatkov iz order booka
- Izračun najboljših nakupnih in prodajnih cen
- Izračun spread-a v EUR in odstotkih
- Pretvarjanje valut USD/EUR
- Spremljanje cen v živo
- Shranjevanje zgodovine cen v CSV
- Grafični prikaz zgodovine cen

## Uporabljene tehnologije

- Python
- Requests
- Matplotlib
- REST API

## Namestitev

Namesti odvisnosti z ukazom: python -m pip install -r requirements.txt

## Zagon

Zaženi glavni program: python orderbook/main.py
